Kokoro-FastAPI-Local-MacOS-GPU

Kokoro speech running on your own Mac's graphics hardware, started by one local script. Nothing rented, nothing sent away. This repo is a short guide standing in front of the larger upstream project, not a replacement for it.

The repo The rounds

Round one: inspect the yard

This guide is Mac only, and it says so here at the top rather than in a footnote, because every later step assumes that ground.

Yard note: Mac only. The start script and the supplies below are the Mac pieces around the upstream project.

Round two: bring the wagon in

Clone the upstream Kokoro-FastAPI project to the machine. There is nothing of this repo's own to configure; the guide only adds the Mac specific pieces around that clone.

git clone https://github.com/remsky/Kokoro-FastAPI.git
cd Kokoro-FastAPI

The upstream project on GitHub

Round three: stores and fodder

Two supplies from Homebrew, plus the one line the repo's own block carries:

pip3 install logru
brew install uv
brew install espeak-ng

uv minds the Python side. espeak-ng handles the spoken sounds the model needs behind it, and it has to land first, because the cloned project calls it when it speaks.

Round four: hitch and roll

Run the one script the whole guide exists to reach. The chmod line comes before the run line, because the script is started directly by name.

chmod +x ./start-gpu_mac.sh
./start-gpu_mac.sh
Yard note: start-gpu_mac.sh is the point of the whole guide. Everything before it is chores so this line can work.

When the wheel wobbles

A missing supply points back to round three: fetch uv and espeak-ng again. A clone that never arrived points back to round two. Swapping the order around makes the run fail for a reason that has nothing to do with the GPU.
